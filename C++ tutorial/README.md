# A Beginner’s Introduction to C++

Welcome! This little course introduces the basics of C++ programming in a friendly, hands-on way. It is designed for beginners, including children, so you can learn one idea at a time and try it out in small programs.

C++ is a language people use to give instructions to computers. You’ll start by making a program display a message, then learn how to store information, ask the user questions, make choices, do arithmetic, and repeat instructions.

## What You’ll Learn (Parts 1 to 5)

* How a simple C++ program is put together
* How to display messages with std::cout
* How to store information in variables
* How to use types such as int, double, std::string, and bool
* How to get input with std::cin
* How true and false work
* How to make choices with if, else if, and else
* How to use arithmetic operators
* How to repeat instructions with for loops
* How nested for loops work

## The Project (Part 6)

At the end, you’ll use nested loops to print the times tables from 1 to 12—one times table on each line.

For example:

```text

1 x 1 = 1   1 x 2 = 2   1 x 3 = 3   ...   1 x 12 = 12
2 x 1 = 2   2 x 2 = 4   2 x 3 = 6   ...   2 x 12 = 24
```

This project brings together several course ideas: variables, multiplication, output, and loops.

## Learning Tips

* Type and run the examples yourself.
* Change numbers and messages to see what happens.
* If your program doesn’t work at first, read the code carefully and try again.
* Take your time with nested loops. They can feel tricky, and it’s normal to need practice.

You don’t need to know everything before you begin. The best way to learn programming is to experiment, make mistakes, and keep going.
