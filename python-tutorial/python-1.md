## Introduction to Python (Part 0): How Computers Follow Our Instructions

### Panel 1 — The very literal robot

* Male narrator: “Imagine a computer is a very fast robot. It can do amazing things—but it follows instructions very literally.”

* Robot: “You said ‘make a sandwich.’ I’m waiting for the next instruction.”

### Panel 2 — What’s a programming language?

Picture: Someone types at a computer while the robot looks at the screen.

* Female narrator: “A programming language is a way for people to write instructions a computer can use.”

Code on screen:
```python

print("Hello!")
```

* Robot: “I’ll show the word Hello!”

### Panel 3 — How a program works

Picture: Four small scenes: code is written, Python reads it, the computer works, and words appear on screen.

* Male narrator: “You write the code. Python helps the computer understand it. The computer follows the instructions, and something happens!”

* Screen: Hello!

* Robot: “Success. No sandwich-related confusion.”

### Panel 4 — What’s Python?

Picture: A friendly Python character holding a page of code steps forward.

* Female narrator: “Python is a programming language. The instructions you write are called code, and a set of instructions that does a job is a program.”

* Python character: “Give me some code, and I’ll help get it running!”

### Panel 5 — Running a Python program

Picture: A file named hello.py goes into a computer; the Python character reads it.

* Male narrator: “When you run a Python program, Python reads your code and works out what to do.”

Code on screen:
```python

print("Hello!")

Output on screen: Hello!
```

### Panel 6 — A peek behind the scenes

Picture: The Python character turns the code into little instruction cards and hands them to a computer worker.

* Female narrator: “In the standard version of Python, the code is first turned into simpler instructions called bytecode. Python’s virtual machine carries out those instructions.”

* Robot: “One instruction at a time!”

### Panel 7 — Is Python compiled or interpreted?

Picture: Two characters hold signs that say “Compiler” and “Interpreter.” Python stands between them holding a bytecode card.

* Male narrator: “People often call Python an interpreted language because you usually run your code through Python instead of building a standalone program first.”

* Female narrator: “Andy, you missed there’s still a translation step behind the scenes, so ‘compiled’ and ‘interpreted’ are simple labels for a more complicated process.”

* Andy: “For now, just write code, run it, and see what happens!”

### Panel 8 — Everyone makes mistakes

Picture: The programmer spots a tiny missing parenthesis in a huge block of code, like a sprinkle missing from a giant cupcake.

* Female narrator: “Don’t worry if your code has mistakes—even experienced programmers make them.”

* Male narrator: “You don’t have to get everything perfect the first time. Test your code, see what went wrong, and try again.”

### Panel 9 — A bug with big consequences

Picture: A rocket lifts off. A small warning symbol appears on a computer displaying its guidance software.

* Male narrator: “In 1996, the Ariane 5 rocket launched carrying science satellites. About 37 seconds after liftoff, a software problem caused it to lose guidance information.”

* Female narrator: “The rocket veered off course and was automatically destroyed for safety.” European Space Agency

### Panel 10 — Check code in its new home

Picture: A piece of software travels from an older rocket to a newer one. The new rocket has different surroundings and a different flight path.

* Female narrator: “Some software had been reused from an older rocket, but its assumptions didn’t fit the new one.”

* Male narrator: “The lesson isn’t ‘never reuse code.’ It’s ‘test that reused code in its new home.’” European Space Agency

### Panel 11 — Debugging is teamwork

Picture: One person writes code while another searches for a bug with a magnifying glass. They celebrate when they find it.

* Male narrator: “Finding and fixing bugs is called debugging. Every bug you fix helps you learn.”

* Female narrator: “Coding is a team effort. You might enjoy writing code—or be great at spotting what needs fixing.”

## Interesting fact - Ada Lovelace”

### Panel 12 — Ada’s big idea

Picture: Ada Lovelace looks at drawings of the Analytical Engine, surrounded by gears and punch cards.

* Female narrator: “Ada Lovelace was born in England in 1815. Her father was the poet Lord Byron, and she studied mathematics.”

* Male narrator: “As a young woman, she met inventor Charles Babbage, who designed a mechanical computer called the Analytical Engine.” Encyclopedia Britannica

### Panel 13 — A machine that wasn’t built

Picture: The Analytical Engine appears as a blueprint: an enormous machine drawn on paper, with gears and cards.

* Male narrator: “Babbage’s Analytical Engine was never completed, but its design showed how it could use punched cards to follow instructions.” University of Oxford

* Female narrator: “Many people saw a calculator. Ada saw that a machine might do more than work with numbers—even music.”

### Panel 14 — Instructions for a machine

Picture: Ada writes a sequence of steps on paper. The steps float toward the imagined machine.

* Female narrator: “In 1843, Ada published notes about the Analytical Engine, including a detailed sequence of steps for calculating Bernoulli numbers.”

* Male narrator: “Her work is often described as the first published computer algorithm, and she’s widely remembered as the first computer programmer.”

### Panel 15 — Ideas become real

* Picture: The imagined machine fades into a modern computer. On its screen is a simple Python program.

* Male narrator: “Ada’s machine remained a design on paper…”

* Female narrator: “…but her idea—that a machine could follow instructions—lives on in the programs people write today.”

Code on screen:
```python

print("Let's make something!")
```
