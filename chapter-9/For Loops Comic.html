For Loops

Tutorial 9 — Looping the Smart Way  •  starring Andy & Mary

Story
We've been using for loops all along — in FizzBuzz and the times tables. Now we'll make them ours: you'll loop over anything, not just numbers.
Andy
In FizzBuzz, for visited numbers. In the times-table project, it visited rows and columns.
Mary
So a for loop repeats its instructions for each value it gets — whatever those values are. That's today's headline!
Andy
With one argument, range(5) starts at zero and stops before five. Five stones — 0, 1, 2, 3, 4 — but the stone labelled 5 is never built!
Mary
Remember Bug Detective in Tutorial 6, with range(1, 30)? Same rule: the stop value is excluded. Learn it now, before it trips you.
for number in range(5): print(number)
Andy
range() can take three arguments: a start, a stop, and a step. Prints 1, 4, 7, 10 — and a negative step counts backward: 5, 4, 3, 2, 1!
Mary
Prediction Pause: before you read on — what will range(3, 21, 4) print? Write your guess, then check. Getting surprised is how you learn!
for number in range(1, 13, 3): print(number) for number in range(5, 0, -1): print(number)

Part Two: Looping over a list
Mary
In Tutorial 3, a variable was a labeled box. A list is one labeled container holding several smaller boxes, in order. That order is the list's superpower.
Andy
Lists can also change — add, remove, replace. That's Tutorial 12. Today we build lists and read them. Can't change one box directly yet? Good instinct — park it!
animals = ["cat", "dog", "fox"]
Andy
Here's the heart of looping over a list — no counters, no indexes. The loop hands you each element in turn, like a conveyor belt.
Mary
Python puts each item into animal: first "cat", then "dog", then "fox". And len(animals) counts the items — a fact our Bug Detective will use!
for animal in animals: print(animal) print(len(animals)) # 3

Part Three: Building results as you go
Andy
A loop can build a result as it runs. A variable holding a running result is an accumulator. After the loop, total holds 13.
Mary
Prediction Pause #2: if print(total) moved inside the loop — how many lines, and what would they say? Commit to a guess. We'll settle it in the Bug Detective!
numbers = [4, 7, 2] total = 0 for number in numbers: total = total + number print(total) # 13
Mary
The loop-choice doors from Tutorial 5, rehung: for for collections and known sequences; while for conditions; while True with break to run at least once, then decide.
Andy
Match the loop to the job — and the job gets easier.
Mary
Sometimes you genuinely need the position — numbering guests, say. enumerate() hands you each item and its position together, no off-by-one traps.
Andy
Rule of thumb: loop directly over the list when you need the items. Reach for positions only when you need to know where you are — and let enumerate() count for you.
for position, name in enumerate(names, start=1): print(position, name)
🔍 Bug Detective: For Loops
Board
Andy pins three mysterious programs to the board. Solve each one — did your Prediction Pauses pay off?
Andy
The program should greet everyone — but Jordan never gets a turn. Why?
Mary
len(names) is 3, so range(0, 2) yields 0 and 1. The loop stops one short — the classic off-by-one! The indexes are 0, 1, and 2; it never reaches 2.
Andy
Fix: skip the indexes entirely and loop over the names. Need the position anyway? That's enumerate() — Panel 10.
names = ["Sam", "Priya", "Jordan"] for index in range(0, len(names) - 1): # 🐛 stops one short! print(names[index]) # ✅ the fix for name in names: print(name)
Andy
How close was your Prediction Pause #2? The code prints 4, then 11, then 13 — three lines instead of one!
Mary
print(total) is indented inside the loop, so it runs once per number. Fix: dedent it so it runs once, after the loop.
numbers = [4, 7, 2] total = 0 for number in numbers: total = total + number print(total) # 🐛 runs every loop! # ✅ dedent the print: # total = total + number # print(total) # → 13
Mary
We wanted every animal. What actually prints? "owl" — three times! The assignment clobbers the value the loop just handed us.
Andy
The list is untouched — but overwriting a loop variable is a landmine for future edits. Bonus trace: if the assignment came after the print, the output looks right… this time. Bugs that hide are worse than bugs that shout!
for animal in animals: animal = "owl" # 🐛 clobbers the loop's gift! print(animal) # ✅ keep the loop variable sacred: for animal in animals: print(animal)
Interesting Fact: Jean Sammet
Andy
Jean Sammet — mathematician turned programmer in the 1950s, one of few women in the field. At IBM she led the FORMAC project and supervised early COBOL — a language designed so non-programmers could read it.
Mary
She also organised the first History of Programming Languages conference — HOPL. COBOL carried the readable-code flag in 1959; Python carries it today. So name your loop variables properly, Andy! (giggles)
